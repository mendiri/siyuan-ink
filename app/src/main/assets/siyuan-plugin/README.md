# SiYuan Ink (plugin)

Muestra encima de los PDF las anotaciones a lápiz hechas con la app **SiYuan Ink** en una tablet Boox,
en la misma posición en que se escribieron. Las anotaciones se leen de `data/storage/siyuan-ink/pdf/`.

Pulsa **Editar tinta** en la esquina del PDF para dibujar con ratón o tableta gráfica (con presión), borrar, deshacer y guardar.
